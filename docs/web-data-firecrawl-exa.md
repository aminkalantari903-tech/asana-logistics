# ارتقای سامانه لجستیک آسانا با Firecrawl و Exa — نقشهٔ قابلیت‌ها

> بر پایهٔ مستندات رسمی (docs.firecrawl.dev v2، exa.ai/docs و صفحات قیمت) — مهر ۱۴۰۵. قیمت‌ها و محدودیت‌ها ممکن است تغییر کنند.

## ۱. خلاصهٔ دو ابزار

| | Firecrawl | Exa |
|---|---|---|
| نقش اصلی | «استخراج» از صفحه/سایت معلوم: scrape، crawl، map، batch، parse اسناد، تعامل با مرورگر، پایش تغییرات | «جست‌وجو و پژوهش» در وب: search (instant/fast/auto/deep)، contents، answer، agent، monitors، websets |
| خروجی ساخت‌یافته | قالب `json` با schema، `query`، `highlights`، `product`، `summary`، اسکرین‌شات | `outputSchema` در Deep Search و Agent با استناد سطح‌فیلد (grounding) |
| تازگی داده | `maxAge` (کش) / واکشی تازه، change tracking (git-diff / JSON) | `maxAgeHours` (livecrawl)، فیلتر تاریخ انتشار، اخبار در چند دقیقه قابل جست‌وجو |
| زمان‌بندی | Monitor (صفحه، سایت، کل وب) با `goal` و داوری AI؛ اعلان webhook/ایمیل/Slack | Monitors API: جست‌وجوی دوره‌ای + حذف تکراری + webhook |
| اسناد | `/parse`: PDF، Word، Excel، PPT → Markdown، بلوک‌های چیدمان، JSON | PDF در contents |
| مرورگر | Interact / Browser Sandbox (Playwright، پروفایل ماندگار، Live View، CDP) | — |
| داده‌های تخصصی | شاخص دولتی (قوانین/مقررات)، پژوهشی، توسعه‌دهنده | اخبار، بازارهای مالی (ارز، کالا)، شرکت‌ها و افراد، حقوقی و تحریم، آب‌وهوا و مکان‌ها؛ Exa Connect (Macrobond و…) |
| قیمت | اعتباری: scrape/crawl ۱ اعتبار/صفحه، JSON +۴، search ۲/۱۰ نتیجه، interact ۲–۷/دقیقه، monitor ۱/صفحه/بررسی؛ رایگان ۱٬۰۰۰/ماه، Hobby ۵k ≈ ۱۶–۱۹$، Standard ۱۰۰k ≈ ۸۳$ | پرداخت به‌ازای مصرف: search ۴–۷$/۱k، contents ۱$/۱k صفحه، answer ۵$/۱k، deep ۱۲–۱۵$/۱k، monitors ۱۵$/۱k، agent ۰٫۰۱۲–۱$/اجرا؛ ۱۰$ رایگان ماهانه |
| امنیت | محدودسازی کلید به endpoint/قالب، IP allowlist، بررسی prompt injection، حذف PII، ZDR | ZDR (سازمانی)، SOC 2 |

**تقسیم کار پیشنهادی:** نشانی را می‌دانیم → Firecrawl (یا Exa Contents برای متن ساده و ارزان). نشانی را نمی‌دانیم / پرسش باز → Exa Search/Answer/Deep. سایت پویا یا نیازمند ورود → Firecrawl Interact. سند (PDF/Excel) → Firecrawl Parse. رخداد دوره‌ای → Monitor هر دو (Firecrawl برای تغییر صفحهٔ مشخص، Exa برای «خبر تازه دربارهٔ موضوع»).

## ۲. فهرست قابلیت‌های قابل افزودن به پلتفرم

### الف) نرخ و هزینهٔ روز
1. **جمع‌آوری خودکار نرخ حمل از صفحات عمومی** فورواردرها/خطوط (Firecrawl scrape + `json` schema: مسیر، تجهیزات، نرخ، سورشارژها BAF/THC/PSS، اعتبار) → ورود به بانک نرخ با وضعیت «در انتظار تأیید» و منشأ (URL، زمان، اطمینان).
2. **شاخص‌های بازار حمل** (WCI/FBX/SCFI و گزارش‌های هفتگی) با Monitor + change tracking JSON → «شاخص روز مسیر» و هشدار جهش نرخ؛ فقط از منابعی که مجوز استفاده دارند.
3. **برآورد بازار با Exa Deep Search** و `outputSchema` (بازهٔ نرخ، زمان ترانزیت، سورشارژ، منابع) برای مسیرهای بدون نرخ؛ با برچسب «برآورد وب» و استناد در «چرا؟» کنترل خودکار.
4. **قیمت سوخت و بانکر** (صفحات عمومی بانکر، قیمت گازوئیل کشورهای مسیر) → به‌روزرسانی مدل هزینهٔ جاده‌ای و BAF.
5. **نرخ ارز و کالاهای پایه** از Exa Financial Markets (EUR/USD، USD/AED، USD/CNY، برنت) کنار منبع ارز داخلی فعلی؛ مقایسهٔ دو منبع و هشدار اختلاف.
6. **ارزش‌گذاری کالا** با قالب `product` / جست‌وجوی قیمت → کنترل منطقی بودن ارزش اظهاری و برآورد بیمه.
7. **هزینه‌های بندری و ترمینال** (تعرفه‌های منتشرشدهٔ بنادر و ترمینال‌ها، PDF) با Parse → جدول THC/انبارداری/دموراژ برای D&D.

### ب) جاده، مرز و عملیات
8. **وضعیت جاده‌ها و انسداد** (اطلاعیه‌های راهداری، پلیس‌راه، هواشناسی مسیر) با Monitor صفحه + Exa «Weather & Places» → ریسک لحظه‌ای مسیر و زمان ترانزیت جاده‌ای.
9. **صف و زمان انتظار مرزها** (بازرگان، سرخس، میرجاوه، مرزهای ترکیه/ارمنستان/عراق) از صفحات رسمی و اخبار → افزودن به زمان ترانزیت و سناریوها.
10. **برنامهٔ کشتی و تأخیر** از صفحات عمومی خطوط/بنادر (Firecrawl؛ در صورت نیاز Interact) → به‌روزرسانی ETA و هشدار جاماندن از Cut-off.
11. **رهگیری کانتینر بدون API رسمی** با Interact و پروفایل ماندگار در پورتال‌هایی که حساب دارید → رویدادهای ردیابی (در صورت مجاز بودن در شرایط سایت).
12. **ازدحام بندر و اعتصاب** با Exa Monitors (اخبار) → یافتهٔ ریسک در کنترل خودکار و قانون اعلان.

### ج) گمرک، مقررات و ریسک
13. **پایش بخشنامه‌ها و تعرفه‌ها** (گمرک، سامانهٔ جامع تجارت، وزارت صمت، نرخ ارز گمرکی) با Monitor و `goal` («فقط تغییر حقوق ورودی یا ثبت سفارش») → به‌روزرسانی مرحلهٔ تعرفه و هشدار.
14. **غربال تحریم و طرف معامله** (Exa Legal & Public Records، Companies & People؛ شاخص دولتی Firecrawl برای مقررات خارجی) → کارت ریسک طرف تجاری/کشتی/بندر.
15. **خوراک ریسک ژئوپلیتیک مسیر** (تنگهٔ هرمز، دریای سرخ، تنش‌ها) با Exa News + فیلتر تاریخ و highlights → امتیاز ریسک مستند به منبع.
16. **پاسخ مستند دستیار** با Exa Answer («THC جبل‌علی چند است؟») همراه استناد.

### د) اسناد و سوابق
17. **خواندن فاکتور، بارنامه، Packing List و پیش‌فاکتور** با Firecrawl Parse + JSON → ثبت خودکار در سوابق و تطبیق «هزینهٔ واقعی با برآورد»؛ حذف PII در صورت نیاز.
18. **استخراج پاسخ استعلام‌ها** (ایمیل/PDF فورواردر) به جدول مقایسهٔ RFQ.

### ه) فروش، تأمین‌کننده و شبکه
19. **یافتن فورواردر/حمل‌کننده برای یک مسیر** با Exa Websets/Agent (معیار: مسیر، خدمات، گواهی‌ها؛ غنی‌سازی: ایمیل، تلفن، وب‌سایت) → پیشنهاد گیرندهٔ RFQ.
20. **پروفایل تأمین‌کننده** با Map/Crawl سایت → خدمات، دفاتر، تجهیزات.
21. **رصد رقبا و بازار** (قیمت و خدمات اعلامی) با Monitor سایت.

### و) سیستم ایجنتیک و کنترل خودکار
22. **مرحلهٔ جدید «بازار زنده» در کنترل خودکار**: پیش از تصمیم، نرخ/ریسک/مقررات تازهٔ همان مسیر از وب گرفته و با مدل مقایسه می‌شود.
23. **منشأ و اطمینان هر عدد**: URL، زمان واکشی، بُرش متن؛ دو منبع مستقل = اطمینان بالاتر؛ ناسازگاری = یافتهٔ «نیازمند بررسی».
24. **پایش‌های پس از اجرا روی وب** (گسترش پایش v15.19): وصل کردن watch به Monitors هر دو سرویس و دریافت webhook در سرور.
25. **ابزارهای عامل‌ها**: افزودن `web.search`، `web.scrape`، `web.extract`، `doc.parse` به عامل‌های داخلی (یا MCP هر دو سرویس) با سقف هزینه برای هر اجرا.
26. **پژوهش عمیق ناهمگام** (Exa Agent / Firecrawl Agent) برای پرسش‌های سنگین؛ نتیجه با JSON و استناد در گزارش.

### ز) زیرساخت اتصال (لازمهٔ همه)
27. **ماژول «منابع وب» سرور**: کلیدهای `IFA_FIRECRAWL_KEY` و `IFA_EXA_KEY` فقط سمت سرور؛ رجیستری منابع (URL، schema، دوره، مقصد داده)؛ صف تأیید انسانی؛ کش؛ تلاش مجدد.
28. **بودجه و مصرف**: سقف روزانه/ماهانه، داشبورد مصرف اعتبار/دلار، توقف خودکار در عبور از سقف.
29. **امنیت**: لیست مجاز دامنه‌ها، `checkPromptInjection`، محدودسازی کلید، امضای webhook، عدم ارسال دادهٔ محرمانهٔ مشتری به جست‌وجو.
30. **کیفیت داده**: تشخیص دادهٔ پرت نسبت به بانک نرخ، برچسب کهنگی، تاریخچه و Snapshot برای بازآزمایی.

## ۴. محدودیت‌ها و ریسک‌ها (مهم)
- **تحریم و دسترسی:** هر دو شرکت آمریکایی‌اند؛ ثبت‌نام، پرداخت و فراخوانی API از ایران ممکن است مسدود باشد. سرور اتصال باید خارج از ایران (یا با مسیر شبکهٔ مجاز) اجرا شود و پرداخت با کارت بین‌المللی انجام شود. پیش از تعهد، شرایط استفادهٔ هر سرویس را بررسی کنید.
- **سایت‌های ایرانی:** فایرکراول پراکسی ایران ندارد (نزدیک‌ترین: امارات، ترکیه)؛ بسیاری از سایت‌های دولتی ایران IP خارجی را مسدود می‌کنند. برای این منابع، یک جمع‌آورندهٔ داخلی (همین سرور در ایران) لازم است.
- **پوشش فارسی Exa** نسبت به منابع انگلیسی کمتر است.
- **مجوز داده:** شاخص‌های حمل تجاری و پورتال‌های خطوط شرایط استفاده دارند؛ فقط منابع مجاز.
- **دقت:** استخراج با LLM خطا دارد؛ هیچ نرخی بدون تأیید انسانی وارد قیمت‌گذاری نمی‌شود و هر عدد منشأ دارد.
